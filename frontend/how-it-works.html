How It Works

Understand the full flow for Sanitization and Document Intelligence.

Sanitization pipeline

End-to-end anonymization for images, PDFs, docs, and text.

1. Ingest

Upload file to the sanitization workspace with configurable rules.

2. Detect

OCR + PII + face detection run in ensemble mode for stronger recall.

3. Transform

Apply blur, pixelate, or blackbox only where needed.

4. Export

Download sanitized results with summary statistics in headers.

Intelligence pipeline

Folder-based search and bulk transformations at scale.

1. Group

Create named folders and organize mixed file types in one workspace.

2. Search

Search by text, number, image OCR cues, or signature terms.

3. Select Similar

Choose selected items, all files, or similar file types for batch jobs.

4. Bulk Export

Run transformation and download grouped ZIP outputs with summary.json.
