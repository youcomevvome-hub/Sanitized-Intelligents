API Documentation

Integrate Sanitizer into your backend with our REST API.

Base URL

https://your-sanitizer-instance.com

Authentication

The API is documented here with an example access key. If you enable auth on the backend, send the key as a header.

X-Access-Key: youNeedAccessAsk

Model stack

Faces

YOLOv8-face + RetinaFace ensemble

OCR

EasyOCR with PaddleOCR fallback

PII

Presidio + spaCy + regex fallbacks

Video identity

ArcFace embeddings for selective blur

Endpoints

GET /health

Check API health and configuration.

Response

{
  "status": "ok",
  "version": "0.1.0",
  "face_backend": "ensemble",
  "ocr_backend": "easyocr"
}

Example (curl)

curl -X GET http://localhost:8000/health
POST /sanitize

Sanitize a single file (image, PDF, DOCX, video, or text).

Request (multipart/form-data)

file: (binary) — The file to sanitize
options: (JSON string) — Redaction configuration

Options Schema

{
  "mask_mode": "blur",           // "blur" | "pixelate" | "blackbox"
  "blur_kernel": 51,             // kernel size (must be odd, 11-151)
  "redact_faces": true,          // detect and mask faces
  "redact_numbers": true,        // detect and mask ID/account/date numbers
  "redact_pii": true,            // detect and mask named PII (emails, phones, etc.)
  "keywords": ["keyword1"],      // additional keywords to redact
  "custom_patterns": [],         // regex patterns to redact (e.g., ["NID-\\d{8}"])
  "ocr_langs": ["en"],           // OCR languages (default: auto-detect)
  "whitelist_face_ids": [],      // for video: faces to NOT blur
  "blacklist_face_ids": []       // for video: faces to blur only
}

Response Headers

Content-Type: image/png (or application/pdf, etc.)
Content-Disposition: attachment; filename=sanitized_...
X-Sanitizer-Summary: {"faces": 2, "numbers": 5, "pii": 1, "total": 8}

Example with access key

curl -X POST http://localhost:8000/sanitize \
  -H "X-Access-Key: youNeedAccessAsk" \
  -F "file=@photo.jpg" \
  -F 'options={"mask_mode":"blur","blur_kernel":51,"redact_faces":true}' \
  -o sanitized.jpg

Example (Python)

import requests

url = "http://localhost:8000/sanitize"
files = {"file": open("photo.jpg", "rb")}
options = {
    "mask_mode": "blur",
    "blur_kernel": 51,
    "redact_faces": True,
    "redact_numbers": True,
    "redact_pii": True,
    "keywords": ["SECRET"]
}

response = requests.post(
    url,
    files=files,
    data={"options": str(options).replace("'", '"')}
)

# Save sanitized file
with open("sanitized.jpg", "wb") as f:
    f.write(response.content)

# Check detections
summary = response.headers.get("X-Sanitizer-Summary")
print(f"Detections: {summary}")

Example (JavaScript/Node)

const fs = require('fs');

const formData = new FormData();
formData.append('file', fs.createReadStream('photo.jpg'));
formData.append('options', JSON.stringify({
  mask_mode: 'blur',
  blur_kernel: 51,
  redact_faces: true,
  redact_numbers: true,
  redact_pii: true,
  keywords: ['SECRET']
}));

fetch('http://localhost:8000/sanitize', {
  method: 'POST',
  body: formData
})
.then(r => r.blob())
.then(blob => {
  fs.writeFileSync('sanitized.jpg', blob);
  console.log('Sanitized!');
});
POST /sanitize/info

Analyze a file without returning the sanitized output (returns JSON detection stats only).

Response (JSON)

{
  "total_detections": 8,
  "by_kind": {
    "face": 2,
    "number": 5,
    "pii": 1
  }
}
POST /sanitize/video

Sanitize video with optional selective face blur (whitelist/blacklist specific identities).

Request (multipart/form-data)

file: (binary) — Video file to sanitize
options: (JSON string) — Redaction config (same as /sanitize)
reference_faces: (optional, files) — Reference images for identity matching

Selective Blur Logic

  • No whitelist/blacklist: All faces blurred
  • Whitelist only: Only faces matching reference images are blurred
  • Blacklist only: All faces blurred except those matching reference images

Supported File Types

Images

.jpg, .jpeg, .png, .tif, .tiff, .bmp, .webp

Documents

.pdf (digital & scanned), .docx (with embedded images)

Video

.mp4, .avi, .mov, .mkv, .webm

Text

.txt, .csv, .md, .json

Deployment

Deploy Sanitizer using Docker:

# CPU (default)
docker-compose up -d

# GPU (CUDA 12)
docker-compose -f docker-compose.yml -f docker-compose.gpu.yml up -d

HTTP Status Codes

200 Success — file sanitized or info returned
400 Bad request — invalid options or unsupported file type
413 Payload too large — file exceeds size limit (200MB default)
415 Unsupported media type
500 Server error — processing failed
